## 🚀 Projects

### 📊 [Freelance Data Analytics Engineer](https://drive.google.com/drive/folders/1_-9cjuvaTQ8QiF5jRFXD01ZaGKn6TOZ-?usp=sharing) &nbsp;<sub>`2025 - 2026`</sub>

Designed and delivered business intelligence dashboards for Saudi Arabian clients in partnership with Rowad Modern Engineering, translating raw business data into actionable reporting for stakeholder decision-making. Delivered 8 training sessions (5 Power BI, 3 Excel) covering data modeling, DAX, and dashboard design, equipping the client's team with hands-on analytics skills.

### ☁️ [EPL Cloud Analytics Pipeline](https://github.com/Moaaz-Elhaiys/EPL_Cloud_Analytics_Pipeline) &nbsp;<sub>`Apr. 2026`</sub>

Architected a full cloud data infrastructure on GCP (GCS + BigQuery) using Terraform for Infrastructure-as-Code, and orchestrated the end-to-end ELT pipeline with Bruin for reliable, repeatable deployment. Engineered a Python/dlt extraction pipeline to ingest nested JSON from external REST APIs into a centralized data lake, then wrote advanced SQL transformations in BigQuery to model raw staging data into a production-ready reporting schema exposed through an interactive Looker Studio dashboard.

### 🗺️ [Smart Delivery Route Optimization Platform](https://github.com/Moaaz-Elhaiys/smart-delivery-route-optimization-platform) &nbsp;<sub>`Jul. 2026`</sub>

Architected an end-to-end geospatial analytics platform integrating Apache Airflow, Spark, Apache Sedona, PostGIS, and Google Cloud Storage to automate data ingestion, spatial processing, and delivery analytics at scale. Optimized vehicle routing using Apache Sedona and OR-Tools, combining spatial hotspot detection and distance analysis to generate efficient, data-driven delivery routes.

### 🚗 [Egypt Cars Market Analytics Pipeline](https://github.com/Moaaz-Elhaiys/Egypt_Cars_Market_Analytics_Pipeline) &nbsp;<sub>`Jul. 2025`</sub>

Built a containerized, end-to-end data pipeline processing 348K+ Egyptian car listings from Hatla2ee using Scrapy, PostgreSQL, Bruin, and Docker Compose, with an incremental ELT workflow using URL-based upserts and `updated_at` watermarks to cut re-run processing to only new or modified listings. Modeled a Kimball-style PostgreSQL star schema with automated data-quality checks for completeness, uniqueness, and valid measures, then connected the warehouse to Power BI to build interactive dashboards analyzing pricing trends, vendor performance, vehicle origins, and geographic distribution.
